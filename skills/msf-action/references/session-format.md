# Action session summary

Name `YYYYMMDD-HHMM-<topic>.md`, adding a numeric suffix on collision.

Include:

- timestamp, mode, named plan path, and run-log path;
- status (`completed`, `partial`, or `blocked`);
- tasks completed and first incomplete task;
- key implementation decisions or compatible deviations;
- verification evidence and known failures;
- blockers, risks, and exact next action.

Write for fast recovery by a fresh agent. Record conclusions, not a transcript, full diff, or duplicate development log.
