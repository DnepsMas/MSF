# Plan session summary

Name `YYYYMMDD-HHMM-<topic>.md`, adding a numeric suffix on collision.

Keep it short and retrieval-friendly:

- timestamp, mode, strength, status (`draft`, `approved`, or `blocked`);
- user goal and working-report path;
- repository evidence inspected;
- decisions and rationale;
- assumptions confirmed or rejected;
- unresolved questions or blockers;
- exact next action.

Record conclusions, not a transcript. Do not duplicate the full report. Update `.msf/memory/project.md` separately only when knowledge remains useful beyond this change.
