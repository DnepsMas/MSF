# Agent 编排画布动画计划

## 元数据

- 计划 ID：`2026-09-15-agent-canvas-demo`
- 状态：`approved`
- 规划强度：Light
- 日期：2026-09-15

## 目标

在当前 MSF 仓库中增加一个零依赖、可直接在浏览器打开的概念演示页，用动画和基础交互呈现类似 ComfyUI 的 Agent 编排体验：用户在无限画布上组织不同类型的上下文节点，通过连线让 Agent 与 Subagent 感知 Memory、Skill、Prompt、命令窗口、模型 API 和其他会话上下文。

## 非目标

- 不接入真实模型 API、终端、浏览器或会话后端。
- 不实现账号、权限、持久化、多人协作或生产级工作流引擎。
- 不实现完整节点编辑器、任意端口规则、循环检测或真实任务调度。
- 不引入 npm、构建工具或第三方前端依赖。

## 当前发现

- 当前仓库是 MSF 工作流工具，业务内容以 Python 安装及校验脚本、技能包和测试为主。
- 仓库目前没有前端框架、网页入口或资源构建流程。
- `.msf/` 工作区有效，尚无已有计划需要替换。
- 为了让演示易于测试且不干扰现有工具链，适合使用独立的静态 HTML 页面。

## 已批准设计与决策

### 交付形态

- 新增 `demo/agent-canvas/index.html`，将结构、样式和脚本集中在单个文件中。
- 页面无需安装依赖或启动开发服务器，可直接通过现代桌面浏览器打开。
- 不修改现有 Python 安装器、验证器和 MSF 技能行为。

### 视觉结构

- 使用专业深色工作台风格、无限网格背景和半透明节点面板。
- 画布中央以 Agent 为主要汇聚节点，Subagent 为下游执行节点。
- 展示 Memory、Skill、Prompt、Terminal、Browser、Session、Model API、Agent 和 Subagent 等节点类型。
- 各节点类型采用稳定的强调色、图标或短标签，并显示简洁状态。

### 动画叙事

1. 画布与主要节点依次淡入、缩放出现。
2. Memory、Skill、Prompt、Terminal、Browser、Session 和 Model API 依次与 Agent 建立连线。
3. 连线出现流动高光或粒子，表示上下文正在传递。
4. Agent 从等待态切换为运行态，并触发 Subagent。
5. Subagent 完成后，画布显示本轮编排完成的视觉反馈。
6. 用户可以重新播放整段动画。

### 基础交互

- 节点可拖拽，连线在拖拽时同步更新。
- 画布支持鼠标拖动平移与滚轮缩放。
- 点击节点可显示选中状态和简短上下文摘要。
- 提供“重新播放”控制，不要求用户刷新页面。
- 动画应尊重 `prefers-reduced-motion`，在减少动态效果时直接呈现稳定终态或使用弱过渡。

3. 建立节点与边的数据描述，并依据节点端口的屏幕位置绘制 SVG 贝塞尔连线。
4. 实现节点拖拽、画布平移、滚轮缩放、节点选择和连线重算。
5. 实现可重放的阶段动画、上下文流动效果和 Agent/Subagent 状态变化。
6. 增加减少动态效果兼容、键盘可聚焦控制以及窄窗口下的基本可用性处理。
7. 在浏览器中完成手工验证，并运行仓库原有测试，确认演示文件没有影响 MSF 工具链。

## 验证

- 直接打开 `demo/agent-canvas/index.html`，页面不依赖网络资源且无阻断性控制台错误。
- 完整动画可以从初始态播放到完成态，并可重复播放。
- 拖动任意节点后，相关连线端点仍与节点保持连接。
- 画布平移和缩放不会破坏节点选择或连线显示。
- 不同节点类型容易区分，Agent 与 Subagent 的关系清晰。
- 在常见桌面宽度以及较窄窗口中检查主要内容不被永久遮挡。
- 启用减少动态效果后，页面仍能清晰展示最终编排关系。
- 运行 `python -m unittest discover -s tests -v`。
- 运行 `python scripts/validate.py`。

## 验收标准

- 用户无需安装依赖即可看到完整演示。
- 页面明确表达“多个上下文节点连接 Agent，Agent 再调度 Subagent”的产品概念。
- 至少展示九种已批准的节点角色或窗口类型。
- 动画、拖拽、平移、缩放、选择和重放均可正常使用。
- 所有资源均为本地内嵌内容，不访问或暴露任何模型凭据。
- 原有 MSF 测试与验证命令继续通过。

## 风险与处理

- 单文件实现可能变长：按数据、渲染、交互和动画分区组织代码，并保持命名清晰。
- SVG 连线与 CSS 变换可能产生坐标偏差：统一在画布坐标系中计算端点，并在拖拽、缩放和窗口变化时重绘。
- 无限画布交互可能与节点拖拽冲突：以事件目标区分节点拖拽和背景平移，并明确管理指针捕获。
- 动画过多可能影响性能或可读性：限制同时运行的粒子数量，并提供减少动态效果路径。

## 阻塞项

无。视觉细节可以在已批准的专业深色工作台方向内由执行 Agent 完成，不影响范围或架构。
